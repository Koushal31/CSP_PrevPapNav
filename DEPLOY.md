# Deploying PapersNav to Render

## 1. Push to GitHub
`.env`, `.venv`, `__pycache__` and uploaded PDFs are gitignored and will **not**
be pushed (secrets stay private).

```bash
git init
git add .
git commit -m "PapersNav"
git branch -M main
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main
```

## 2. MongoDB Atlas — allow Render to connect (required)
Render's outbound IPs are dynamic, so in Atlas:
**Network Access → Add IP Address → `0.0.0.0/0` (Allow access from anywhere).**
Without this the app cannot reach the database and the deploy will fail on boot.

## 3. Create the Render service
- New → **Blueprint** and pick this repo (Render reads `render.yaml`), **or**
  New → **Web Service** with:
  - Build: `pip install -r requirements.txt`
  - Start: `gunicorn wsgi:app --bind 0.0.0.0:$PORT --workers 2 --timeout 120`
  - Health check path: `/healthz`

## 4. Set environment variables (Render → Service → Environment)
`SECRET_KEY` is auto-generated by `render.yaml`. Set the rest from your local
`.env` values:

| Key | Notes |
|-----|-------|
| `MONGO_URI` | your Atlas connection string (secret) |
| `MONGO_DB_NAME` | `previous_papers_navigator` |
| `ADMIN_EMAILS` | comma-separated admin emails |
| `ALLOWED_EMAIL_DOMAINS` | e.g. `vignaniit.edu.in` |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | from Google Cloud Console |
| `GOOGLE_REDIRECT_URI` | `https://csp-prevpapnav.onrender.com/auth/google/callback` |
| `MAIL_USERNAME` / `MAIL_PASSWORD` / `MAIL_DEFAULT_SENDER` | Gmail + **App Password (no spaces)** |
| `FLASK_ENV` | `production` (already in render.yaml) |

> `MAIL_SERVER`, `MAIL_PORT`, `MAIL_USE_TLS`, `MAIL_USE_SSL` are already set in `render.yaml`.

## 5. Google Cloud Console
APIs & Services → Credentials → your OAuth client → **Authorized redirect URIs**,
add exactly:
```
https://csp-prevpapnav.onrender.com/auth/google/callback
```
OAuth consent screen: set to **Internal** (Workspace) so college accounts can sign in.

## 6. Seed the catalog (once, after first deploy)
Render → your service → **Shell**:
```bash
flask --app run seed-viit
flask --app run seed-view
```

## 7. Verify
Open `https://csp-prevpapnav.onrender.com/healthz` → should return
`{"status": "ok", "database": "up"}`.

---

### ⚠️ Uploaded files don't persist on Render's free tier
The free plan has an **ephemeral filesystem**, so PDFs saved to `static/uploads/`
are wiped on every restart/redeploy. All other data (users, paper records,
posts, messages) lives in MongoDB Atlas and persists fine. To make uploads
permanent, store files in **MongoDB GridFS** or a service like Cloudinary/S3.
